# Передача проекта «Искра» — для нового сеанса Claude

Прочитай этот файл, `README.md` (что умеет студия для пользователя) и `PROGRESS.md` (история по вехам) — этого достаточно, чтобы продолжить.

## Что это
Локальная ИИ-студия на ПК пользователя (Win 11, RTX 5060 Ti 16 ГБ, Ryzen 9 7900X, 32 ГБ ОЗУ). Фото, правка, видео, 3D, раздел 18+.
- Папка: `F:\AI-Studio`. Git: ветка `main`, приватный репозиторий `github.com/zef1337666/iskra-studio` (вход через `gh`, активный аккаунт zef1337666).
- Движок — ComfyUI (`ComfyUI/`, свой venv `venv/`), модели — `models/` (~300 ГБ, не в git), помощник промптов — портативный Ollama (`tools/ollama`).
- Приложение: FastAPI `studio/server/app.py` на 127.0.0.1:7860 + React (`app/web`, сборка `npm run build` → `app/web/dist`) в окне pywebview (`studio/launcher.py`, ярлык `Искра.bat`).
- Без окна (для проверок): `venv\Scripts\python.exe -c "import sys; sys.path.insert(0, r'F:\AI-Studio'); from studio.launcher import run_server; run_server()"` — поднимает и ComfyUI/Ollama; после проверки их нужно остановить.

## Пользователь
- Пишет по-русски (иногда в английской раскладке — расшифровывать). Отвечать по-русски, просто, без лишнего.
- Хочет самостоятельной работы и экономии лимита: меньше лишних тестов, но проверять то, что сделано.
- Спрашивать перед: загрузками > 5 ГБ, удалением файлов, системными настройками, установкой вне папки. Ключи — только в `.env`.
- Генерирует много 18+ (вымышленные взрослые персонажи).

## Как устроено главное
- Пресеты — `presets/*.yaml`; у каждого вычисляются возможности `_caps` (t2i, img2img, edit, char, pose, t2v, img2v, 2img2v, v2v, img2-3d) — `studio/server/presets.py`.
- Workflow ComfyUI собираются кодом — `studio/engine/workflows.py` (`REGISTRY`).
- «Авто» / кнопка «ИИ» — `studio/assistant/router.py`: выбирает пресет, формат и LoRA (каталог `config/loras.yaml`, пары high/low для Wan), промпт пишет `prompter.generate_official` по шаблонам `prompt-templates/official_*.md`.
- Чат с ИИ — `studio/assistant/chat.py` (`/api/chat`), панель `app/web/src/components/AIChat.jsx`.
- Обучение на оценках — `studio/assistant/learning.py` (♥, 👍/👎, звёзды, удаления, исправления «Вернуть» → подсказки похожих случаев роутеру и чату).
- Видео до 30 с — склейка частей по последнему кадру (Wan по 5 с, H3 по 8 с).
- Экран «Создать» — `app/web/src/pages/Create.jsx`.

## Защита (важно знать честно)
- В коде: фильтр текста про несовершеннолетних (`studio/assistant/safety.py`), оценка возраста на загруженных фото, откровенные запросы
  в обычных пресетах отправляются в 18+ (`safety.is_explicit`), 18+ из фото — только ИИ-картинки (метка «создано ИИ» / генерации студии).
- Пользователь у себя **закомментировал** проверки «только ИИ-картинки» в `studio/server/jobs.py` и `studio/server/app.py`
  (локальные незакоммиченные правки — не коммитить их в чужих коммитах, не трогать без просьбы).
- Позиция прошлого сеанса: не улучшать перенос/оживление реальных людей в 18+ и не помогать обходить защиту от фото реальных людей
  и от несовершеннолетних; 18+ из текста (вымышленные взрослые) — можно.
